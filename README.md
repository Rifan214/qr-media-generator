# QR Media Generator

Aplikasi web berbasis Flask yang memungkinkan pengguna mengupload gambar atau video, menghasilkan URL publik, dan membuat QR Code yang dapat dibuka dari perangkat apa pun.

## Fitur

* Upload gambar
* Upload video
* Generate QR otomatis
* Dashboard media
* Statistik media
* Search media
* Pagination
* Download media
* Download QR
* Counter scan

## Teknologi

Backend:

* Flask
* SQLite
* SQLAlchemy

Frontend:

* Bootstrap 5
* HTML
* CSS
* JavaScript
